# ℹ️ Термины Java
### ☕ `Java` - это объектно-ориентированный язык программирования.
### ⚙️ `JVM` - это виртуальная машина Java, которая выполняет байт-код.
### ▶️ `JRE` - это среда выполнения Java, содержит в себе JVM и стандартные библиотеки.
### 🛠️ `JDK` - это набор инструментов для разработки Java-программы, содержит в себе javac, JRE и инструменты.
### 📄 `Байт-код` - это специальный промежуточный код.
### 📦 `Переменная` - это именованная область памяти, которая хранит в себе значение определенного типа данных.
### 🔗 `Переменная-ссылка` - это переменная, которая хранит ссылку на объект.
### 🧩 `Тип данных` - это атрибут, который определяет: сколько памяти выделять, какие значения можно хранить и какие операции можно проводить.
### ➕ `Оператор` - это специальный символ или конструкция, который выполняет определенное действие.
### 1️⃣ `Операнд` - это значение, над которым происходит операция.
### ✏️ `Ключевое слово` - это слово, зарезервированное языком Java.
### 🏗️ `Класс` - это схема для создания объектов.
### 🧱 `Поле` - это переменная, которая описывает класс.
### ⚙️ `Метод` - это именованный блок кода, который выполняет действие и запускается при его вызове.
### 🐣 `Конструктор` - это метод, который запускается при создании объекта.
### 👤 `Объект` - это экземпляр класса.
___
### Ⓜ️ `Maven` - это инструмент для автоматизации сборки и управления зависимостями.
### 🧪 `JUnit` - это фреймворк для автоматического тестирования Java-программ.
### 🔒 `Инкапсуляция` - это принцип ООП, который скрывает внутренние данные и предоставляет доступ к ним через специальные методы.
### 🧬 `Наследование` - это принцип ООП, который позволяет дочернему классу перенимать поля и методы родительского класса.
### 🎭 `Полиморфизм` - это принцип ООП, который дает возможность использовать один интерфейс (или родительский класс) для работы с разными типами объектов.
