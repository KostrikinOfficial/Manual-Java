## 📋 `List`
### `List` - это...
Интерфейс, представляющий упорядоченную коллекцию элементов.

Например: `Андрей` `Антон` `Мария` `Иван`

У каждого элемента есть позиция: `0 → Андрей` `1 → Антон` `2 → Мария` `3 → Иван`

### Важно
- `List` сохраняет порядок элементов,
- `List` допускает дубликаты.

### `List` - интерфейс...
Вот это: `List<String>` - само по себе не конкретный объект.

Например: `List<String> names = new ArrayList<>();`

Здесь: `List` - интерфейс (тип ссылки), А: `ArrayList` - конкретная реализация (реальный объект).

## 📦 `ArrayList`
### `ArrayList` - это...
Конкретная реализация `List`.

Пример: `ArrayList<String> name = new ArrayList<>();`

Но обычно пишут: `List<String> name = new ArrayList<>();`

Потому что код зависит от интерфейса: `List<String>`, а не от конкретной реализации.

## ➕ `add()`
### Основная операция
`names.add("Андрей");` - добавляет элемент в конец списка.
### `add(index, element);`
`names.add(1, "Иван");` - можно указать позицию.

## 🎯 `get()`
### Получить элемент по индексу
`String name = names.get(0);` - получить элемент с индексом 0.

Но если индекса не существует, получим: `IndexOutOfBoundsException`

## ✏️ `set()`
### Заменяет существующий элемент
`names.set(1, "Иван");` - заменяет, а не добавляет.

## ➖ `remove()`
### Удалить элемент по индексу
`names.remove(1);` - после удаления, индексы сдвигаются.

## 🔢 `size()`
### Количество элементов
`names.size()`

## 👀 `contains()`
### Проверка, есть ли элемент
`names.contains("Андрей");` - результат `true` или `false`

## 🫙 `isEmpty()`
### Проверить, пустой ли список
`names.isEmpty()` - `true`, если ни одного элемента нет.

## 🔄 Перебор списка
### Можно использовать `for-each`
    for (String name : names) {
        System.out.println(name);
    }

На практике `for-each` часто удобнее, если нам не нужен сам индекс.

## 1️⃣ `List<Integer>`
Коллекции работают с объектами, поэтому `List<int>` нельзя.

Почему `Integer`, а не `int`? Потому что коллекции хранят объекты, а:

`int → примитивный тип`

`Integer → объект`
