# 🧬 Наследование, `extends`, родительские и дочерние классы
### Наследование - это...
Возможность одного класса получить поля и методы другого класса.
### Если проще, наследование - это...
Когда один класс получает возможности другого класса и может добавлять свои.
### Например:
    class Character

    ПОЛЯ
    int hp;
    int mana;
    int lvl;
    String name;

    МЕТОДЫ
    void go()
    void fight()
Теперь, глядя на этот базовый класс можно создать ещё один - конкретный. Например, для гоблина, и сказать - "Пусть он наследуется от основного!":
    
    class Goblin extends Character

### Что это значит?
Когда мы наследуем один класс от другого, то по сути, говорим что в таком классе наследнике есть невидимая копия всего, что находится внутри базового класса:

    class Goblin extends Character

    УНАСЛЕДОВАЛИ (Скрыто)
    int hp;
    int mana;
    int lvl;
    String name;

    void go()
    void fight()

Теперь, у нас по сути два одинаковых класса. Только в одном из них все поля и методы невидимые.
### Но зачем?
Дело в том, что в классе-наследнике мы теперь можем добавлять и новые методы, которые уникальны именно для него. Впридачу к тем, что унаследованы от базового.
### Например:
    class Goblin extends Character

    МЕТОДЫ
    void trick() {
    }

Гоблин получает особый навык хитрости, который доступен только ему. Чтобы создать нового персонажа мы просто взяли некоторую основу для всех и добавили туда то, что делает нашего - уникального.
### Но что если мы теперь хотим добавить класс ещё одного персонажа?
    class Zombie extends Character

    ВСЁ ИЗ Character

Посмотрите, как это стало легко благодаря наследованию. Теперь нам осталось лишь добавить уникальный навык для зомби и мы можем создать хоть 100 персонажей очень легко.
### В этом и состоит суть принципа наследования в ООП: Вынести общие поля и методы из нескольких классов в один базовый класс, что устраняет дублирование кода.
## 🆔 Отношение `is-a`
### `is-a` означает отношение: "является".
Например, из примера выше: `Goblin is-a Character`, то есть: Гоблин является Персонажем.

Поэтому мы можем написать: `Character character = new Goblin();`, потому что Гоблин - это Персонаж.
### Другие примеры:
`Dog is-a Animal`, `Car is-a Vehicle`, `Student is-a Person`, так как Собака это Животное, Машина это Транспорт, Студент это Человек.

В тоже время, `Car is-a Engine` - Машина это Двигатель будет неверно ❌

Это уже не наследование, а отношение `has-a` - имеет.
## 🧩 Отношение `has-a`
### `has-a` означает отношение: "имеет".
Он показывает, что один объект содержит в себе другой объект.
### Например:

    class Car

    ПОЛЯ
    Engine engine;

    class Engine

    МЕТОДЫ
    void start()
### Здесь: `Car has-a Engine` - Машина имеет Двигатель.
## ❗ Наследование - это не просто убрать дублирование!
### Новичок часто думает:
«Если у нескольких классов есть одинаковые поля, значит надо сделать наследование!»

Но так не всегда! Главный вопрос: «Есть ли реальная логическая связь is-a?». Например:

`Goblin is-a Character` ✅

`Car has-a Engine` ❌
## 🛡️ `protected`
### `protected` - это специальный модификатор.
Он позволяет доступ внутри самого класса, его наследникам некоторых классов того же package.

Но `protected` нужно использовать осознанно. В реальном проекте предпочтительнее сохранять данные закрытыми: `private` и предоставлять доступ через методы.
