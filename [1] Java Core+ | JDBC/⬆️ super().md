# ⬆️ `super`
___
### `super` - это...
Ключевое слово, которое позволяет обратиться к конструктору / полю / методу родительского класса.
## 🐣 `super()`
### `super()` - это...
Вызов конструктора родительского класса, а в круглых скобках перечисляется список аргументов.

Он должен быть первым выражением в конструкторе дочернего класса! Потому что родительская часть должна быть инициализирована прежде выполнения остальной части конструктора.
### Например:
`super(String name, double balance)`
## 🧱 `super.field`
### `super.field` - это...
Обращение к полю родительского класса.
### Например:
`super.name`
## ⚙️ `super.method()`
### `super.method()` - это...
Вызов метода родительского класса, в круглых скобках также перечисляется список аргументов.
