## 🏛️ Абстрактный класс
### Абстрактный класс - это...
Класс, который предназначен для использования в качестве основы других классов и не может быть напрямую создан через `new`.

Абстрактный класс отвечает на вопрос: «Что это за сущность?»

Например: `abstract class Employee { ... }`

❌ Нельзя: `Employee employee = new Employee();`

✅ Но можно: `Employee employee = new Developer();`
## ⚙️ Абстрактный метод
### Абстрактный метод - это...
Метод, который не содержит реализации. А неабстрактный класс наследник должен его переопределить.

Например: `public abstract void introduce();`
