## 🔌 Интерфейсы
### Интерфейс - это...
Договор или набор правил, который говорит классу: «Если ты реализуешь меня, ты обязан иметь эти методы».

Интерфейс отвечает на вопрос: «Что эта сущность имеет?»

Например:

    interface Flyable {

        void fly();

    }

Смысл: Всё, что является `Flyable`, должно уметь `fly()`
### Класс реализует интерфейс через: `implements`

Например: `class Bird implements Flyable { ... }`

### `implements` - это контракт.

Если написать:

    interface Flyable {

        void fly();

    }

то интерфейс говорит: «Я не обязательно знаю, как ты умеешь летать, но если ты заявляешь что ты `Flyable`, у тебя должно быть соответствующее поведение».
